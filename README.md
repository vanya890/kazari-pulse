# Pulse Drift

Киберпанк-раннер для Telegram Mini App. Поймай сигнал, пролети ворота, держи комбо.

[![Pulse Drift — играть](https://img.shields.io/badge/Pulse%20Drift-играть-62f6e0?style=for-the-badge)](https://vanya890.github.io/kazari-pulse/)
[![GitHub](https://img.shields.io/badge/GitHub-Исходники-181717?style=for-the-badge&logo=github)](https://github.com/vanya890/kazari-pulse)

## Что это

Pulse Drift — ритмичный гейт-раннер. Тап/Space поднимает неоновый дрон, он медленно опускается. По дороге летят ворота с растущей частотой и сужающимся проёмом. Чистый проход — комбо растёт, счёт растёт. Столкновение — конец. Рекорд хранится локально.

## Установка и запуск

```sh
npm install
npm run dev      # локальная разработка
npm run build    # production сборка
npm run deploy   # сборка + деплой в Telegram Serverless
```
